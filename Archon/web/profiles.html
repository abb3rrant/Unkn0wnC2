HTTP Listener Profiles
Profiles describe the complete HTTP/HTTPS wire shape: ordered request headers, operation-specific headers, response headers, URIs, methods, codecs and TLS. Archon stores them, embeds them in beacons, and delivers assigned profiles live to listeners.
